一、最终技术选型确认
 
- 开发语言：Python
- 配套推荐技术栈：
- PDF渲染核心：PyMuPDF（fitz），高性能页面渲染与坐标处理
- 桌面GUI框架：PySide6 / PyQt6，实现窗口、右键菜单、交互事件
- Markdown支持：可通过  markdown  库转HTML配合Qt内置组件渲染，或直接使用第三方Markdown编辑组件
 
 
 
二、完整需求详细清单
 
1. 基础PDF阅读能力
 
- 支持打开本地PDF文件，正常渲染显示PDF页面内容
- 支持基础翻页、页面缩放操作，可适配窗口大小调整
 
2. 笔记锚定交互逻辑
 
- 右键触发：在PDF页面的任意位置点击鼠标右键，弹出自定义右键菜单，包含「添加笔记」选项
- 点位锚定：笔记精准绑定右键点击的PDF页面对应位置；页面缩放、窗口尺寸变化时，锚点始终对应PDF原文的同一点位，不会错位
- 可视化标记：已添加笔记的位置，在页面上显示可见标记（彩色小圆点），直观标识笔记对应位置
- 笔记预览位置：点击彩色小圆点，在右侧边栏显示笔记内容，避免遮挡正文，同时笔记的编辑和管理也都在右侧边栏进行
 
3. 笔记内容与格式
 
- 格式要求：笔记内容支持 Markdown 格式，具备编辑与渲染预览能力
- 查看交互：点击页面上的笔记锚点标记，弹出笔记窗口，展示渲染后的Markdown笔记内容
- 编辑能力：支持对已有的笔记内容进行修改、编辑

4. 数据存储规则
 
- 外置独立存储：所有笔记数据完全独立保存，不修改、不写入原始PDF文件
- 本地持久化：关闭程序后重新打开同一份PDF，所有笔记可正常加载显示
- 锚点存储方案：采用「页码 + 归一化坐标（0~1区间的相对比例坐标）」存储锚点位置，确保不同缩放比例、窗口大小下位置精准
 
5. 基础笔记管理
 
- 同一份PDF可添加多个不同位置的笔记，互不干扰
- 支持删除已添加的笔记
